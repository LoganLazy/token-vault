隐私政策

生效日期：2026 年 7 月 20 日

Token Vault 是一个本地优先的 TOTP 验证码管理工具。本政策说明应用如何处理你的数据。

本地数据

默认情况下，账号名称、TOTP 密钥、设置和使用统计保存在当前浏览器的本地存储中，不会由应用主动发送给第三方。启用主密码后，保险库使用 PBKDF2-SHA256 和 AES-256-GCM 加密；未启用主密码时，本地数据不会被加密。

可选私有同步

登录自托管同步服务后，账号数据会发送到你所连接的 Token Vault 服务端。服务端会加密数据库中的 TOTP 密钥，但同步目前不是端到端加密：服务端在处理请求时能够解密这些密钥。服务的部署者负责服务器、日志、备份和访问控制。

摄像头与网络

摄像头仅在你主动选择扫描二维码时使用，图像在设备上解析，不会上传。应用不集成第三方广告或分析服务。安装后的 PWA 会缓存静态资源以支持离线使用，但不会缓存 API 响应或带授权信息的请求。

导入、导出与剪贴板

你选择的导入文件在设备上处理。导出的备份由你保管；未选择备份加密时，文件包含明文 TOTP 密钥。复制验证码会将当前验证码写入系统剪贴板。

删除数据

你可以在应用中删除单个或全部账号。清除该站点的浏览器数据会删除本地保险库和设置。使用私有同步时，还应在同步服务中删除对应账号或数据；服务端备份的保留周期由部署者决定。

安全提示

请使用 HTTPS 部署同步服务，设置强主密码，并妥善保存加密备份。忘记本地主密码后，Token Vault 无法恢复加密数据。
