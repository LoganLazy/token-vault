# TOTP Hub

🔐 安全便捷的两步验证码管理工具 - 中文优化版

## 🎯 特性

### 🔒 企业级安全（v1.1.0 新增）
- **主密码加密存储** - PBKDF2 + AES 256-bit 加密
- **启动解锁验证** - 设置后每次打开需要密码
- **手动锁定功能** - 随时一键锁定应用
- **密码强度验证** - 至少 8 位，大小写字母+数字
- **随机盐值保护** - 防止彩虹表攻击
- **内存安全** - 解密数据只存在于内存

### ✨ 核心功能
- **现代化界面** - 采用暖色调设计，简洁优雅
- **扫码添加** - 调用摄像头扫描二维码
- **URI 导入** - 支持 otpauth:// 格式快速导入
- **搜索和分类** - 快速找到需要的账号
- **实时刷新** - 自动生成验证码，带倒计时
- **一键复制** - 快速复制到剪贴板
- **暗色模式** - 夜间友好的深色主题

### 📱 用户体验
- **完全移动端适配** - 支持手机、平板等各种设备
- **服务商图标** - 30+ 常见服务自动识别
- **7 大分类** - 工作/个人/金融/社交/开发/其他
- **备份与恢复** - 支持加密备份
- **完全离线** - 所有数据本地存储，不联网

## 技术栈

- **前端框架**: React 18 + Vite
- **样式**: Tailwind CSS v4
- **图标**: Lucide React
- **TOTP 生成**: OTPAuth
- **语言**: JavaScript (JSX)

## 使用说明

### 添加账号

1. 点击右上角"添加账号"按钮
2. 选择以下两种方式之一：
   - **从 URI 导入**: 粘贴 `otpauth://totp/...` 格式的 URI
   - **手动填写**: 输入服务商、账号名称和密钥

### 管理账号

- **复制验证码**: 点击卡片上的"复制验证码"按钮
- **删除账号**: 点击卡片右上角的垃圾桶图标

### 高级选项

在添加账号时展开"高级选项"可以配置：
- **算法**: SHA1 / SHA256 / SHA512（默认 SHA1）
- **位数**: 6-8 位（默认 6 位）
- **周期**: 15-60 秒（默认 30 秒）

## 数据安全

### 🔒 主密码保护（推荐）
- ✅ **PBKDF2 密码哈希** - 10,000 次迭代，防暴力破解
- ✅ **AES-256 加密** - 军事级加密标准
- ✅ **随机盐值** - 每个密码都有唯一的 128-bit 盐值
- ✅ **启动解锁** - 设置后每次打开需要验证
- ✅ **手动锁定** - 随时可以锁定应用
- ⚠️ **忘记密码无法恢复** - 请妥善保管密码

### 📦 备份与恢复
- ✅ 导出 JSON 格式备份
- ✅ 支持密码加密备份文件
- ✅ 可在不同设备间迁移
- ⚠️ 建议定期备份

### 🛡️ 隐私保护
- ✅ 所有数据完全本地，零网络请求
- ✅ 不发送任何数据到服务器
- ✅ 完全离线可用
- ✅ 开源透明，代码可审计
- ⚠️ 清除浏览器数据会丢失所有账号（除非有备份）

> 💡 **最佳实践**：设置主密码 + 定期导出加密备份 = 安全无忧
> 
> 详细安全说明请查看 [SECURITY.md](SECURITY.md)
