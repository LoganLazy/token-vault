# TOTP Hub

🔐 安全便捷的两步验证码管理工具 - 中文优化版

## 特性

- ✨ **现代化界面** - 采用暖色调设计，简洁优雅
- 📱 **移动端适配** - 完美支持手机、平板等各种设备
- 🔒 **本地存储** - 所有数据存储在本地 localStorage，不联网
- ⏱️ **实时刷新** - 自动生成 TOTP 验证码，带倒计时
- 📋 **一键复制** - 快速复制验证码到剪贴板
- 🚀 **快速导入** - 支持从 TOTP URI 一键导入
- ⚙️ **灵活配置** - 支持自定义算法、位数、周期

## 技术栈

- **前端框架**: React 18 + Vite
- **样式**: Tailwind CSS v4
- **图标**: Lucide React
- **TOTP 生成**: OTPAuth
- **语言**: JavaScript (JSX)

## 快速开始

### 安装依赖

```bash

```

### 启动开发服务器

### 构建生产版本

```bash
npm run build
```

构建产物在 `dist` 目录

## 使用说明

### 添加账号

1. 点击右上角"添加账号"按钮
2. 选择以下两种方式之一：
   - **从 URI 导入**: 粘贴 `otpauth://totp/...` 格式的 URI
   - **手动填写**: 输入服务商、账号名称和密钥

### 管理账号

- **复制验证码**: 点击卡片上的"复制验证码"按钮
- **删除账号**: 点击卡片右上角的垃圾桶图标

### 高级选项

在添加账号时展开"高级选项"可以配置：
- **算法**: SHA1 / SHA256 / SHA512（默认 SHA1）
- **位数**: 6-8 位（默认 6 位）
- **周期**: 15-60 秒（默认 30 秒）

## 数据安全

- ✅ 所有数据存储在浏览器本地 localStorage
- ✅ 不发送任何数据到服务器
- ✅ 完全离线可用
- ⚠️ 建议定期备份数据（导出功能开发中）
- ⚠️ 清除浏览器数据会丢失所有账号
